## ✨ About

**Myla** is a multipurpose Discord bot created to bring useful systems, entertainment, moderation, customization, and personality to Discord communities.

More than just a collection of commands, Myla is designed around her own identity and community experience.

The project is continuously evolving, with new features, improvements, and community-driven ideas being introduced over time.

---

## 🚀 Features

Myla currently provides a variety of systems designed to make Discord communities more enjoyable and easier to manage.

### 🛡️ Moderation

Tools to help server staff keep their communities organized and safe.

- Ban
- Unban
- Kick
- Timeout
- Warnings
- Message clearing
- Channel locking
- Slowmode
- Automatic punishments
- Moderation utilities

### 🎮 Entertainment

Fun commands designed for everyday interaction.

- 8Ball
- Ship
- AFK
- Social interactions
- Random utilities
- And more

### ℹ️ Utility

Useful information and server tools.

- User information
- Server information
- Avatar tools
- Member count
- Bot information
- Reminders
- Help system

### ⭐ XP & Social Systems

Myla includes systems designed to make interaction with the bot feel more personal.

Users can progressively build their relationship with Myla through activity and unlock special roles and interactions.

### ⚙️ Configuration Panel

Myla provides an interactive configuration panel designed to make server setup easier.

Server administrators can configure different systems without having to manually manage complicated commands.

### 🎫 Tickets

A configurable ticket system for community support and staff interaction.

### 💡 Suggestions

Community members can submit suggestions while staff can review and manage them directly through Discord interactions.

### 🤖 AutoMod

Myla includes automatic moderation systems designed to help detect and handle unwanted content and behavior.

### 💰 Economy & Social Features

Additional systems are being developed to make Myla increasingly interactive and useful as a community companion.
